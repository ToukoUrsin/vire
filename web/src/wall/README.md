# Hall wall

`#/wall` (big screen, or stacked on a phone), `#/wall?u=<userId>` (a visitor's own dot), `#/wall/poster` (A4 print).
Data: `GET /api/wall` (`server/wall.ts`). `?demo=<n>&h=<hour>` shows simulated data with a visible tag.

Run output is kept out of the repo: screenshots of every state and the poster PDF are in
`/bulk2/runs/depression/wall/` (no backups).
